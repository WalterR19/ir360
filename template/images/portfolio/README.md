# Imágenes del Portafolio

## Instrucciones

Por favor, agrega las capturas de pantalla de los sitios web en esta carpeta:

### Imágenes necesarias:

1. **dare-to-experiences.jpg**
   - Captura de pantalla del sitio: https://daretoexperiences.com/
   - Resolución recomendada: 1200x800px o superior
   - Formato: JPG o PNG

2. **equanime.jpg**
   - Captura de pantalla del sitio: https://equanime.cl/
   - Resolución recomendada: 1200x800px o superior
   - Formato: JPG o PNG

## Cómo capturar las imágenes:

1. Abre cada sitio web en el navegador
2. Toma una captura de pantalla de la página principal (preferiblemente el hero/banner inicial)
3. Recorta la imagen para que muestre la parte más representativa del diseño
4. Guarda con el nombre exacto indicado arriba
5. Coloca los archivos en esta carpeta (`template/images/portfolio/`)
